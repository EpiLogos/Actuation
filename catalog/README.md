# Actuation target facts

These versioned JSON documents are declarative source, not observed installations.
`actuation-adapters::Catalog` admits them, the native observation ports measure an
actual environment, and the public detection record retains the difference.
A model inventory reports provider-native offerings; it does not select a model.
An environment marker reports native context; it cannot identify an Agent or grant
authority. Capability installation seams describe supported target mechanics, not
permission for this process to install them.

`harnesses.json` and `capabilities.json` share catalogue revision 6. Their target
facts were extracted without semantic change from accepted source
`1c862c6bf58478adf6842a090214906dd2337001`; the frozen cross-language catalogue test
checks the entire documents, not only the revision numbers. `secret-sources.json`
retains its independent revision 1 and fingerprint-only observation contract.
Adding or changing a target is a source revision, not a new generic Agent type.
Declare provenance, update both target catalogue revisions together, and exercise
native measurement/refusal tests. Do not add guessed capabilities to fill a gap.

During the serial migration, Node remains the served product until R7. The old
MJS descriptors are temporary migration/oracle residue, not a second maintained
catalogue or specimen-native exemption. Their final retirement belongs to R7/R9.
