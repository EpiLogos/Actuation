# Actuation

Actuation is the developmental and reference home for first-class agentic actuation in the EpiLogos system.

It exists to make the ontology, contracts, reference implementations, and experiments for agents and harnesses explicit without making this repository the mandatory residence of agent instances. In normal use an agent inhabits the Central world/directory to which it is bound; Actuation supplies reusable semantics and experimental/runtime material for how agency is constituted, differentiated, related, and returned.

The repository is intentionally number-neutral: labels such as `#0` and `#1` are profile or coordinate designations, not generic runtime types. Their final ordering remains a separate constitutional question.

Substantive foundation work is developed through reviewable branches and pull requests.
