# Epistemic Cultivation Experiments

This directory is the Actuation proving ground for the programme defined in [`docs/EPISTEMIC-CULTIVATION-AND-MODEL-INTERIOR-RESEARCH.md`](../../docs/EPISTEMIC-CULTIVATION-AND-MODEL-INTERIOR-RESEARCH.md).

The programme studies **epistemic form as both inherited structure and deliberate cultivation**.

It therefore combines two directions:

```text
DISCOVERY
human corpus → trained model → latent organisation → model-interior study

CULTIVATION
human/agent epistemic craft → corpus/dialogue/annotation → adaptation/context → changed organisation and agency
```

The two directions meet in controlled experiments.

## Research object

The experimental object may include any combination of:

- a model/checkpoint/adapter;
- a harness or loop;
- a QL process condition;
- an MEF disclosure/refraction condition;
- an authored or generated corpus;
- annotations and provenance;
- an AIKit research profile;
- model-interior observations/interventions;
- agent Judgement Space;
- external behaviour, Actions and Returns.

## First programme

The initial series should establish six linked stages:

1. **Baseline** — hookable open-weight model, no explicit QL cultivation.
2. **Structural discovery** — QL-structured but QL-unnamed tasks across heterogeneous semantic domains, with matched controls.
3. **Epistemic cultivation** — human-authored and agent-assisted L0/L0′ + MEF corpus generation with source/derivation provenance.
4. **Adaptation** — compare context/retrieval, recurrence/harness, SFT/adapter, preference/contrastive and activation-level interventions as available.
5. **Interior comparison** — hidden trajectories, workspace/J-space behaviour, causal interventions and TDA/trajectory analysis.
6. **Reproduction and return** — second model family plus O:I projection of attributable experiments/findings into the shared research field.

No stage should claim later-stage evidence early. In particular, a corpus schema or QL-labelled output is not evidence of a corresponding model-interior structure.

## Required controls

Every QL/MEF experiment should make surface imitation distinguishable from structural operation.

Useful controls include:

- shuffled position/process assignments;
- vocabulary-matched examples with broken relational structure;
- topic-matched ordinary prompts;
- alternative low-dimensional decompositions;
- random matched activation directions/subspaces;
- model-family replication;
- lens-language prompts that do not instantiate the lens operation;
- held-out domains in which QL terminology is absent.

## Working artifact kinds

They remain experimental until repeated use justifies stable schemas.

## Data principle

The corpus is part of the experiment, not a disposable input blob.

Every dataset or generated dialogue should preserve enough provenance to answer:

```text
what source/world did this come from?
who or what authored/generated it?
what QL/MEF operation was applied?
what model/profile generated any synthetic material?
what human/agent editorial return occurred?
what revision entered training/evaluation?
```

Human-authored structure and agent-generated material must remain distinguishable.

## QL principle

QL is not operationalised here as six arbitrary labels.

Experiments should test positional relation, transition, conjugacy, recursion, return, topology and process homology. The base sixfold may structure an experiment silently; explicit QL naming is only required where naming itself is an experimental variable.

## MEF principle

MEF is treated as a family of full-field refractions. A lens should transform how the same object is disclosed while preserving the identity/provenance of that common object.

The central comparison is therefore not merely answer diversity. It is:

```text
common object
+ controlled lens/refraction
→ changed disclosure trajectory
→ changed Judgement Space
→ changed model-interior trajectory
→ changed return
```

## Current evidence status

This directory currently establishes the programme only.

It does **not** claim:

- a QL geometry has been found in a model;
- MEF lens transformations have been detected internally;
- an epistemically cultivated model outperforms an uncultivated baseline;
- a psychoid/topological interpretation has been empirically established.

Those are experiment targets. Results, including negative and mixed results, should be committed here with configuration and provenance rather than promoted through prose alone.
