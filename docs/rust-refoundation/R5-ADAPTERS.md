## Native boundary

`actuation-adapters` supplies an immutable admitted catalogue, validated public
observation/capability/model-access documents, typed presence effects, executable
native probes, same-run self-context reading, declared event translation and
fingerprint-only secret-source observations. Its effect result distinguishes a
present fact, a completed negative measurement, and an unavailable mechanism.
Service presence is a typed fact; no generic engine parses diagnostic prose to
infer it. Unsupported inventory stays unavailable, not an empty offering.

Target declarations are maintained under `catalog/`. Native JSON remains readable,
including existing extensions and optional/null spelling. The full original
capability/detection/instantiation/secret wire oracle passes unchanged. Catalogue
revision 6 and secret catalogue revision 1 are preserved because changing data's
storage language does not change its meaning. New target declarations can be
loaded without changing generic core semantics.

The native catalogue implements the stream's `BoundaryCatalogue` port. Native
triggers map only to declared boundaries; custom events retain their honest null
mapping. Model/provider inventory names remain provider facts and directory counts
remain counts. No directory entry becomes an invented model or Agent identity.

R4's temporary `usage_native` source codecs now live exactly once in
`actuation_adapters::usage`. The generic stream continues to own usage observations,
validation, persistence and correlation. The complete 213-case R4 public corpus
still executes, including all 13 relocated Claude/Codex codec cases; the generic
stream alone exercises its 200 cases. No reverse dependency or compatibility
re-export cycle was introduced. This is the source-API move mandated at R4, not a
public JSON contract change.

## Real effects and their limits

Ordinary detection measures files/PATH and declared service endpoints without
executing harness binaries. Version execution is an explicit option. Executable
arguments remain an argument vector, never a shell command assembled from data.
Native process probes have deadlines, bounded output and process-group termination
on supported Unix targets. Tests exercise timeout, noisy output and inherited pipes
using actual controlled processes, not success-shaped receipts.

HTTP observations use native Rust HTTP/TLS, bounded response bodies/deadlines,
no automatic redirects, and no implicit environment proxy. Inline URL credentials
are refused. Missing, non-2xx, malformed, oversized and stalled inventory answers
are not represented as empty inventories. An authenticated inventory whose access
cannot be supplied by the existing observation contract stays unavailable; there
is no new credential resolver here. A service-only descriptor with no compatible
executable/config receipt is explicitly refused because /v1 has no service-only
receipt variant. Daemon process-name observation still uses the existing `pgrep`
mechanism; its absence is disclosed, never simulated. No daemon is installed.

Secret effects expose only location, metadata, SHA-256 and byte length. File reads
are incremental and byte-bounded; matching symlink files are refused with
`O_NOFOLLOW` on the supported Unix targets. Walk budgets, unreadable sources and
unsupported probes degrade coverage. This is not a claim of an OS-level sandbox,
atomic whole-filesystem snapshot or race-free ancestry traversal. Vault output is
reduced at the effect boundary; field values and failure stderr never enter scan
records. The declared Central vault reference remains a source fact/recommendation,
not newly authored human policy or permission to migrate private Control.

## Explicit corrections, not recaptured law

The immutable R5 extraction records original-source answers for three separately
asserted detector defects. They remain visible beside the native corrections:

* A passing executable-absence diagnostic plus a present config directory no longer
  becomes `receipts.executable = "not found on PATH"`, nor a version/hash target.
* A genuinely resolved path containing diagnostic words remains a present path.
* A passing environment-marker read cannot hide failed presence measurement as
  absence. The result remains unavailable without actual presence evidence.

Additional native effect tests make failed filesystem access distinct from absence,
keep partially read declared secret sources unavailable even after a match, and
make vault authentication failure unknown access rather than an absent item.
Successful metadata is not promoted into execution or authority. These corrections
strengthen existing observation laws without renumbering the wire contracts or
regenerating the general R1 oracle. They are controlled reproductions, not claims
about incidents on the user's machine.
