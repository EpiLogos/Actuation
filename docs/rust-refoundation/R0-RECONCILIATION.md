## Proven pre-existing detector defect — R5

With executable resolution `{found:false}` and an existing config directory, detection correctly finds presence but incorrectly selects the passing absence probe. It emits `receipts.executable = "not found on PATH"`; with versions requested it calls `versionProbe("not found on PATH")`. This was reproduced using injected effects and a fixed clock; no production incident is claimed.

False observation is not a semantic law to port. R5 must retain the config-dir receipt and not version-probe a missing executable. Preserve the original as an explicit defect fixture and assert the corrected truth condition separately. Never regenerate the general oracle to bless drift. No cross-owner ticket is needed for this Actuation-local correction.
