# Agent self design v0.2

Start with DESIGN.md for the current-minting integration design. SELF-KITE.md is a complete authored personality source; RELATIONAL-LOGOS.md is its shared encounter form. KITE-LOCAL-TEST.md is their exact deterministic composition for manual placement in a local agent's supported instruction slot. SKILL.md is the source-authoring workflow. SOURCES.md records what was inspected and the limit of verification.

This is an independent successor design, not an overwrite of the earlier M5-based prototype. It introduces no working CLI or deployed schema.
